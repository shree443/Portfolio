Game Features

3-Lane Switching
Smooth left/right lane-change movement across a 3-lane track with input buffering for responsive direction changes.
Lifeline System
Limited lifelines absorb a collision instead of ending the run instantly, giving players a short recovery window.
Hint System
Contextual on-screen hints warn of upcoming obstacle patterns and recommended lane/action just before they arrive.
Multiple Themes
Swappable visual themes reskin the track, obstacles, lighting, and skybox without changing core gameplay logic.
Mode Selection
Choose between different play modes before starting a run, each with its own pacing and difficulty curve.
Procedural Difficulty Scaling
Obstacle density and run speed scale up over distance to keep runs challenging as the score climbs.

Game Modes

Simple
Obstacles limited to jump and left/right lane switches — an easy entry point for new players.
Little Difficult
Adds duck obstacles on top of jump and left/right, requiring quicker reflex combinations.
Difficult
Introduces full-width banner obstacles that block all lanes except one designated entry lane.
More Difficult
Mixes every obstacle type — jump, duck, lane switches, and single-lane banners — at maximum pace.

SYSTEM DESIGN

Lane Switch Flow
Input → Target Lane Check → Interp Move Component → Collision Re-check → Lane Confirmed
Obstacle Spawner Flow
Distance Trigger → Pattern Pool → Lane Assignment → Spawn Actor → Difficulty Scale → Despawn Behind Player
Lifeline Flow
Collision Detected → Lifeline Available Check → Consume Lifeline → Brief Invulnerability → Resume Run
Hint System Flow
Upcoming Pattern Read → Hint Widget Trigger → Display Timing Window → Fade Out → Clear on Pass
Core Architecture
Player Runner Character → Lane/Jump/Duck Components → Obstacle Spawner → Theme Manager → Mode Manager → UI/HUD
// problem solving

Challenges & Solutions

Lane Switch Feel
Problem: Instant lane snaps felt jarring at high speed
Solution: Interpolated lane movement with input buffering
Result: Smooth, responsive lane changes at any speed
Obstacle Pattern Fairness
Problem: Random spawns occasionally created unavoidable combinations
Solution: Curated pattern pool validated for at least one safe path
Result: Every spawn is challenging but always survivable
Lifeline / Hint Sync
Problem: Hint timing didn't always match player reaction window
Solution: Hint trigger distance tuned per obstacle speed tier
Result: Hints consistently arrive with enough reaction time
Theme Swapping Performance
Problem: Swapping themes caused hitches from asset loading
Solution: Async asset streaming and pre-warmed theme pools
Result: Seamless theme changes with no frame drops
